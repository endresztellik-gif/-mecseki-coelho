# Public Assets

Ez a könyvtár tartalmazza a statikus fájlokat, amelyek közvetlenül a build outputba kerülnek.

## Szükséges ikonok (Claude Code-dal generálandók később):

- `pwa-192x192.png` - PWA ikon (192x192px)
- `pwa-512x512.png` - PWA ikon (512x512px)
- `apple-touch-icon.png` - Apple eszközök (180x180px)
- `favicon.ico` - Favicon

## Ikon design javaslat:
- Pasztell színek (rózsaszín-lila gradiens)
- Emoji vagy egyszerű szív/csillag ikon
- Minimalista, tiszta design
- "MC" monogram vagy teljes cím

## Generálási módok:

1. **Online eszközökkel:**
   - https://realfavicongenerator.net/
   - https://favicon.io/

2. **Claude Code-dal:**
   - Generálj egy egyszerű SVG ikont
   - Konvertáld PNG-re különböző méretekben

3. **Placeholder használat:**
   - Jelenleg a Vite alapértelmezett ikonja működik
   - Később lecserélhető

Addig is az alkalmazás működik alapértelmezett ikonokkal!
